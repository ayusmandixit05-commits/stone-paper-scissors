# stone-paper-scissors

A simple Rock Paper Scissors web game built using HTML, CSS, and JavaScript. 
The game allows users to play against the computer with randomly generated moves, 
tracks wins, losses, and ties using browser localStorage, and includes features like 
auto-play mode, reset confirmation, and keyboard shortcuts for better user interaction.

# How to play
1. Click **Rock**, **Paper**, or **Scissors**
2. The computer randomly selects a move
3. The result (Win / Loss / Tie) is displayed
4. Scores are saved automatically

# Features
- ✅Score tracking using `localStorage`
- 🔄 Reset score with confirmation
- 🤖 Auto-Play mode (plays every second)
- ⌨️ Keyboard shortcuts:
  - `A` → Toggle Auto Play
  - `Backspace` → Reset confirmation

# How to play locally
1. Clone or download the repository
2. Open `index.html` in your browser
3. Start playing
